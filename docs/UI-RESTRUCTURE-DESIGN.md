# Personal AI OS 界面重构设计（第一版）

## 1. 目标

将当前长页面仪表盘重构为左侧固定导航、右侧独立页面的个人管理系统。

第一版重点不是增加复杂功能，而是让任务、想法、项目、财务、健康、复盘和 AI 管家各自职责清晰、操作直接。

## 2. 页面导航

左侧导航固定显示：

1. 今日
2. 任务
3. 想法
4. 项目
5. 财务
6. 健康
7. 复盘
8. 管家
9. 归档
10. 设置

点击导航后切换独立页面，不使用长页面滚动定位。

## 3. 数据归档规则

### 需要归档的数据

- 任务
- 想法
- 项目
- AI 管家对话

任务规则：勾选归档，并且状态为“完成”或“取消”时，自动进入任务归档库。

想法规则：勾选归档，并且处理状态为“已处理”时，自动进入想法归档库。

项目和对话支持手动归档。

### 不归档的数据

财务、健康、复盘属于长期记录，不进入归档库，始终保留原始数据。

后续增加“统计”能力，对长期数据按日、周、月进行汇总和精简查看。例如：本周收入、本周支出、平均睡眠时长、运动总时长、复盘中的重复问题等。统计结果是摘要，不删除原始记录。

## 4. 任务页面

使用类似 Notion 的数据库表格，默认显示未归档任务。

字段：

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 归档 | checkbox | 勾选后按自动归档规则处理 |
| 任务名称 | title/text | 必填，可直接编辑 |
| 任务日期 | date | 可选择，按日期倒序排列，最近日期在上面 |
| 状态 | select | 完成、未完成、取消；默认未完成 |
| 备忘 | text | 可直接编辑 |

表格最后一行固定为“添加新任务”。新任务创建后，可以继续编辑所有属性。

建议颜色：未完成灰色、完成绿色、取消红色。

## 5. 想法页面

使用类似 Notion 的数据库表格，默认显示未归档想法。

字段：

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| 归档 | checkbox | 勾选后按自动归档规则处理 |
| 想法内容 | title/text | 必填，可直接编辑 |
| 类型 | select | 项目灵感、长期想法、短期想法 |
| 备注 | text | 可直接编辑 |
| 紧急程度 | select | 1级、2级、3级；1级最紧急 |
| 处理状态 | select | 已处理、未处理；默认未处理 |

按紧急程度升序排列，1级在最上面。表格最后一行固定为“添加新想法”。

建议颜色：项目灵感红色、长期想法蓝色、短期想法橙色；1级红色、2级蓝色、3级绿色。

## 6. 项目页面

项目页面不使用数据库表格作为主视图，而是使用画廊卡片。

### 画廊卡片展示

- 项目名称
- 启动时间
- 项目类别
- 当前状态
- 目标日期
- 目标结果
- 预期收益
- 收益属性

### 参考的项目属性标签

这些选项参考 Notion 项目数据库：

- 项目类别：小型项目（紫色）、中型/阶段性项目（红色）、长期/大型项目（粉色）
- 状态：准备开始（灰色）、进行中（绿色）、完成（红色）
- 收益属性：不适用（灰色）、可能产生（黄色）、明确产生（绿色）

### 项目详情页

点击项目卡片后进入详情页，展示项目资料和 AI 项目设计台。

AI 在项目范围内负责：

- 设计项目目标
- 设计项目阶段
- 生成执行方案
- 将阶段拆分为任务
- 根据进度调整计划
- 更新项目当前情况和备注

项目界面本身只负责项目展示、资料查看和触发对应 AI。项目具体设计交给对应 agent，通过 skill + MCP 处理。

## 7. 财务页面

财务页面参考 Notion 财务系统，分为：

- 快速记账
- 支出记录
- 收入记录
- 资金储备
- 统计（预留）

### 快速录入

提供常用按钮。点击按钮后锁定分类、日期和账户，用户只需要填写事件和金额。

例如点击“吃饭”：

- 大项自动选择：日常消费
- 小项自动选择：饭费
- 日期自动选择：今天
- 用户填写：午餐、25 元

### 支出标签

大项：品质生活（红色）、突发消费（棕色）、日常消费（黄色）、固定支出（粉色）。

小项：饭费（水蓝/蓝色）、水费（灰色）、电费（粉色）、饮用水（绿色）、日用品（红色）、休闲娱乐（棕色）、交通费（粉色）、电话费（黄色）、订阅/分期（灰色）、冲动消费（橙色）、医药（紫色）、生活费（棕色）、其他（灰色）。

### 收入标签

大项：生活费/工资（棕色）、突发/其他收入（粉色）、项目收入（灰色）。

小项：代抢→火山（红色）、中转站项目（紫色）、其他（绿色）、生活费（黄色）。

### 资金储备标签

- 恋爱资金：粉色
- 紧急资金：红色
- 投资资金：蓝色

金额、日期、分类、资金账户、项目关联和备注都需要支持编辑。财务记录不归档。

## 8. 健康页面

参考 Notion 的“饮食与睡眠”和“今日是否自律”数据库。

每日记录字段：

- 日期
- 今日空腹体重
- 昨晚睡觉时间
- 入睡时间
- 起床时间
- 睡眠时间
- 今日运动内容
- 运动时长
- 是否自律
- 备注

主视图为“今日记录 + 历史时间线”。健康记录不归档，未来通过统计查看本周、本月趋势。

## 9. 复盘页面

参考 Notion 的“每日规划与复盘”和“阶段规划与复盘”数据库。

### 每日复盘字段

- 日期
- 今日计划
- AI 观察
- 做得好的
- 遇到的问题
- 今日结论
- 明日调整
- 工作模式反馈
- 状态：草稿、已完成

### 阶段复盘字段

- 关联项目
- 开始日期
- 结束日期
- 目标完成情况
- 保留/停止/调整
- 阶段结论
- 状态：待复盘、已完成

复盘记录不归档。后续增加周复盘、月复盘和问题聚合统计，但保留每日原始记录。

## 10. AI 管家页面

页面采用左右两栏：左侧对话历史，右侧当前对话。

支持：

- 新建对话
- 查看历史对话
- 对话归档和恢复
- 复制对话内容
- 发送文字
- 发送图片
- 图片和文字一起发送

API 配置不放在管家页面，统一放到设置页面。

AI 管家通过 skill + MCP 将项目规划、财务分析、健康建议、复盘等任务交给对应 agent；工作台负责展示对话和结果。

## 11. 归档页面

只展示：

- 任务归档
- 想法归档
- 项目归档
- 对话归档

第一版不做删除和清理，只做查看、筛选和恢复。

## 12. 设置页面

第一版只保留 API 配置：

- Base URL
- 模型名称
- API Key

API Key 不放在普通业务数据库中，不在对话列表中展示。

## 13. 第一版实现顺序

1. 左侧固定导航和独立页面路由。
2. 任务数据库：表格、内联编辑、排序、自动归档。
3. 想法数据库：表格、标签、排序、自动归档。
4. 项目画廊和项目详情页。
5. 财务快捷按钮、分类标签、支出/收入/资金储备页面。
6. 健康每日记录和历史列表。
7. 每日复盘、阶段复盘。
8. AI 管家历史、归档、复制和图片输入。
9. 归档中心和 API 设置。
10. 统计能力预留接口和页面入口。
