# 6. 验收、风险、已锁定决策

## 6.1 验收标准

命令：`pnpm typecheck`、`pnpm test`、`pnpm --filter @paios/web build` 全过。

### 导航

- 十项都在，点击只显示对应页，侧栏不消失、不随内容滚走
- 刷新后 hash 仍停在当前页（例如 `#/tasks`）
- 缺「想法」「归档」算失败
- 任务页不再出现看板/日历（日历若还要，只能在今日，第一版今日也不做看板）

### 任务

- 底行可增，所有列可改
- 按任务日期近→远，无日期在最后
- 未完成灰 / 完成绿 / 取消红
- 仅勾归档、状态未完成：行还在任务页
- 勾归档且完成或取消：任务页消失，归档页出现
- 归档页可恢复，回到任务页且 checkbox 未勾

### 想法

- 底行可增，列可改
- 1 级在最上
- 类型三色、紧急三色
- 勾归档且已处理 → 进想法归档；否则留在想法页

### 项目

- 主视图是大卡片不是表
- 卡片上能看到规格 8 项
- 点卡片进详情，有资料和设计台入口
- 可手动归档，归档页能恢复

### 财务

- 点「吃饭」后只填事件和金额即可记一笔：大项日常消费、小项饭费、日期今天
- 支出/收入表可改金额、日期、分类、账户、项目、备注
- 三个储备账户名称和颜色正确，余额为分换算的元
- 统计 tab 可见但标明未启用
- 财务记录不出现在归档页

### 健康

- 今日能记体重、睡觉、入睡、起床、运动、自律、备注
- 入睡+起床后睡眠时长自动出现
- 历史按日倒序
- 健康不进归档页

### 复盘

- 每日字段齐全，草稿可改，完成后不可改（沿用 finalize 不可变）
- 阶段复盘能选项目和日期
- 复盘不进归档页

### 管家

- 左历史右对话
- 可新建、切换、归档、恢复、复制文本
- 可发文字、可发图片、可图文一起发
- 本页没有 Base URL / Key 输入框
- 设置页可配三项；Key 不明文回显；`paios.db` 和 `GET /settings` 里找不到 key

### 归档

- 仅四类：任务、想法、项目、对话
- 可筛选、可恢复
- 无删除、无清空按钮

### 回归（不得破坏）

- 单写者锁仍有效
- 确认票仍只能 UI 批准，MCP 无 approve 工具
- 金额仍是整数分
- 备份/恢复/导出/ICS·CSV 导入仍可用（入口可在今日或设置底部）
- `pnpm --filter @paios/server mcp` 仍能列出工具并读 `paios://today`

## 6.2 风险

| 风险 | 处理 |
| --- | --- |
| 现有任务 `doing/blocked` 被 UI 压成未完成 | 接受。第一版三态。库值在打开并保存前保持原样；一保存即 `todo` |
| 账户 `daily` 改名为投资资金，旧流水语义漂移 | 只改显示名，id 不变。验收时说明 |
| `App.tsx` 一次性拆太碎导致回归 | 按 05 的 Task 1 先拆壳再迁功能，每阶段 typecheck+test |
| 图片转 data URL 撑爆 LLM 上下文 | 限制 4 张×4MB，失败时保存附件但 chat 只带文件名 |
| 无 git，迁移失败难回滚 | 迁移前走现成 backup；开发用 `.data/` 可删库重建 |
| 页内管家用户以为它会自动改项目 | 设计台文案写明「方案不会自动写库」 |
| CSS 深色/浅色两套都在 | 新组件用现有浅色主视觉（`index.css` 后半段已覆盖），不要再引入第三套主题 |

## 6.3 已锁定决策（不要再问）

1. 路由用 hash，不引入 react-router。  
2. 任务日期用 `due_date`；`scheduled_date` 留给计划算法，表上不出现。  
3. 任务 UI 三态：`todo/done/cancelled`。  
4. 自动归档在 Core 执行，不信任前端单独改 `archived_at`。  
5. 归档勾选是 `archive_requested`，两条件都满足才写 `archived_at`。  
6. 想法类型只暴露三种；其它旧类读作短期想法。  
7. 财务账户三个 id 不变，显示名改为恋爱/紧急/投资资金。  
8. API Key 只在 `{dataDir}/secrets.json`（或环境变量），不进 SQLite。  
9. 页内 LLM 不执行工具调用。  
10. 统计只留入口和空 API，不算数。  
11. 归档页不做删除。  
12. 设置主区只有 API 三项；备份/导入/导出不删，挪到今日快捷或设置底部。  
13. 不改端口、不改单写者、不改确认票 TTL、不绑模型云。  
14. 本计划不打包 MSI。
