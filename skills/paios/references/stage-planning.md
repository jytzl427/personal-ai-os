# Personal AI OS 计划制定原则与规范体系（记忆文件）

## 核心交互铁律（无论阶段计划还是每日计划，必须绝对遵守）
**【严禁一次性全量输出，必须一个板块一个板块来】**
- 无论是制定阶段计划还是每日计划，管家**严禁一次性把所有板块全部列出**！
- 必须严格采取**“一个板块一个板块推进、步步沟通确认”**的交互步调：
  1. 管家呈现当前板块的背景、扫描数据或提议；
  2. 停下脚步，向用户征询意见与指示；
  3. 用户沟通、补充并指示“进入下个板块/确认”后，管家再记录并推进入下一个板块。
- 绝不抢步预设，把主导权和沟通权 100% 留给用户。

## 一、 每日计划制定标准流程（五大板块，单步互动递进）

制定每日计划时，严格按以下五个板块，**逐个板块展开互动**：

- **第一板块：阶段备注与宏观提醒（对齐大方向与复盘提醒）**
  - 呈现当前阶段主线与指标约束；
  - 强调当前阶段的重点倾斜（如：优先安排自媒体与小型项目）；
  - 强制提醒复盘机制（普通日提醒今日复盘；阶段末日提醒阶段复盘+今日复盘）；
  - **停步沟通**：听取用户对今日宏观节奏的指示。

- **第二板块：项目扫描与待办挖掘（主动参谋，激活项目）**
  - 扫描所有活跃项目进度与卡点；
  - 管家主动提议：建议从哪些项目中拉入什么具体小任务加入今日待办；
  - **停步沟通**：听取用户决策，决定哪些项目任务加入待办。

- **第三板块：想法库扫描（灵感流动）**
  - 列出当前想法库（Inbox）；
  - 评估是否有契合主线、可转化为待办的想法；
  - **停步沟通**：听取用户决定是否提拔或排期想法（排期后原想法归档）。

- **第四板块：全量待办任务与习惯清单（强制呈现，绝不遗漏）**
  - 汇总前述板块后，全量列出执行日的所有待办任务完整清单（以 due_date 为准，简明分类：突发处置、项目攻坚、生活琐事、例行维护等）；
  - 列出当日习惯打卡（饮水、刷牙、久坐打断）与数据打卡（称重、餐饮记账）；
  - **停步沟通**：与用户对齐确认今日的总任务盘子。

- **第五板块：分三阶段排期计划（落地执行）**
  - **早（起床启动 ~ 午餐与午休）**：称重、晨起水/牙、启动/例行维护、核心上午攻坚、午餐饮记账、午后刷牙、午休蓄力。
  - **下午**：主要攻坚推进（优先倾斜自媒体与小型项目）、久坐打断走动、下午饮水。
  - **晚上**：收尾攻坚/系统维护、晚餐饮记账、睡前刷牙、全天收支对账、完成每日复盘（阶段最后一天加做阶段复盘）、00:30 前准时就寝。
  - *执行节奏*：先排定第一阶段（早），待用户执行完或再次呼叫时，再逐步展开下午与晚间。

## 二、 阶段计划制定原则与八大板块架构

### 制定节奏与交互原则
1. **用户主导、管家记录**：采用“一点点、一个板块一个板块来”的互动节奏。管家倾听、记录、吸收，绝不抢步预设或擅自做主。
2. **严禁越界**：阶段计划草案通过 period_plans_upsert 生成后，必须由用户在 Web 界面（http://127.0.0.1:4738）手动审核并点击“确认”，管家/Agent 严禁私自将阶段计划标为 confirmed。
3. **想法流转**：已处理/已排期的想法必须及时归档（状态 processed 且 archive），保持 Inbox 清爽。
4. **项目状态**：未归档仅结束的项目（如代抢）保留在列表中作为参考，不能私自标记归档。

### 八大板块标准架构（固定顺序）
- **板块一：主线与生活状态**（核心主线设定、生活琐事清空、身心作息平稳恢复）
- **板块二：复盘板块（复盘驱动）**（复盘上阶段数据，驱动后续板块指标动态调整；首阶段先立架构）
- **板块三：财务计划**（全量记账、日常午晚餐饮限额、冲动消费笔数、娱乐消费笔数）
- **板块四：健康计划**（严格入睡时间、体重趋势管理、有效运动频次、不自律次数容忍上限）
- **板块五：习惯计划**（每日饮水杯数、刷牙频次、久坐打断走动）
- **板块六：想法板块**（聚焦主线沉淀灵感、高急想法排期立项并归档）
- **板块七：项目板块**（小型项目阶段死线归档、长期项目轻量维护、延后项目零负荷、已结束项目暂不归档保留参考）
- **板块八：其他板块**（设立深度思考日、前置事项收尾以尽早衔接学习安排）
